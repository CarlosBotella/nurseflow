NurseFlow: autocompletado de diagnósticos

Escribe al menos tres letras en Diagnóstico principal. Usa flechas y Enter o toca una sugerencia. Escape cierra las sugerencias. La selección conserva el código y la generación de plantilla de contexto original, cuando ese campo está vacío.

Las búsquedas usan la conexión CIE-11 del repositorio original. Necesitan conexión y un Worker operativo. El ZIP no incluye ni cambia ese backend.

Consulta README.md y docs/UI-REFACTOR-STATUS.md para instalación, cambios y comprobaciones.
